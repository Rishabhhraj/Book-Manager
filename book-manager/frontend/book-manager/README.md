# Personal Book Manager

A full-stack MERN application for managing personal book collections.

## Features

- User Authentication (JWT)
- Add Books
- Edit Books
- Delete Books
- Reading Status Tracking
- Tag Filtering
- Dashboard Statistics

## Tech Stack

Frontend:
- React
- React Router
- Axios
- Tailwind CSS

Backend:
- Node.js
- Express.js
- MongoDB
- JWT
- bcryptjs

## Installation

Frontend

npm install
npm run dev

Backend

npm install
npm run dev
